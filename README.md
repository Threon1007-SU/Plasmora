# Plasmora

Plasmora 是供单人在 Windows 本机使用的质粒管理程序。它把导入的 SnapGene `.dna` 文件集中保存在一个仓库中，用分组、Feature 标签、备注和同义词集群帮助查找质粒；打开预览时才读取对应文件并绘制 Feature 图。

## 项目解决什么问题

当质粒文件散落在多个文件夹中，按文件夹分类会产生重复副本，也难以根据构建元件寻找文件。Plasmora 将文件导入统一仓库，并把分组作为数据库中的关联记录：一个质粒可以属于多个分组，分组本身不会复制 `.dna` 文件。程序启动时从本地索引显示列表，选择质粒预览时再解析原件。

## 主要功能

- **导入与整理**：通过按钮或从资源管理器拖入有效的 SnapGene `.dna` 文件；拖到某个分组时同时归入该分组。可更改原件存储目录。
- **分组管理**：一个质粒可加入多个分组；可从全部质粒中批量选择加入分组，也可通过右键菜单修改质粒分组、重命名或删除分组。
- **查找与排序**：搜索文件名、导入时提取的 Feature 标签和备注；可单独开启“搜索引物名称”（默认关闭）。两个范围选项均关闭时只按文件名搜索。支持同义词集群，例如 `ITPR1` 与 `IP3R1`；提供常用文件名、导入时间和文件大小排序。
- **预览与记录**：右侧可切换“质粒图谱”和“引物信息”；按需读取 `.dna` 原件，展示 Feature 或文件中保存的引物名称、完整 5′→3′ 序列、长度、GC% 和结合位置，可复制引物序列。支持备注、收藏和最近查看。
- **文件操作**：右键质粒可重命名、调整分组、在 SnapGene 中打开、导出单个 `.dna` 文件或经二次确认删除。把质粒卡片拖出程序可在目标位置复制一份 `.dna` 文件。
- **按日副本**：设置中可启用“按日更改生成副本”（默认关闭）。保留导入原件，每天首次在 SnapGene 中打开时创建当天工作副本，同日保存更新该副本，跨日继续保存会归入新一天的副本。SnapGene 默认打开最新版本。右键“查看该文件所有副本”，悬停可查看最近五条时间与文件名，单击进入完整副本列表，并切换图谱或引物预览。
- **导出与备份**：批量导出当前列表中选中的质粒为 ZIP，并附带 CSV 清单；可一键备份或恢复本地仓库。
- **数据保护**：后台监听仓库文件变化，在 SnapGene 保存修改后自动更新对应质粒的 Feature 标签、大小和校验值；普通窗口切换不会触发全仓库同步，也不会显示后台同步进度。仍可点击“同步仓库”主动检查全部原件。删除的质粒和替换前版本进入回收站，恢复备份前会自动保存当前仓库。存储迁移会检查空间与文件校验值，并清理中断时留下的副本。
- **操作反馈**：批量导入、导出、仓库同步、备份、恢复和存储迁移显示进度，可在处理当前文件后取消。程序只允许一个实例运行，再次启动会唤起已有窗口。
- **本机设置**：可切换内置配色，包括“企业简洁风”等七套装扮，并设置关闭窗口时退出、最小化到托盘或每次询问。
- **关于与日志**：设置页显示版本、MIT 许可证、项目主页和本机日志入口。

## 安装方法

### 使用 Windows 安装包

从 [GitHub Releases](https://github.com/Threon1007-SU/Plasmora/releases) 获取 `Plasmora-Setup-0.9.0.exe`，运行后按向导完成安装，再从桌面或开始菜单启动 **Plasmora**。安装包面向 64 位 Windows。需要自行构建时，请先按下文安装依赖，再安装 Inno Setup 6 或 7，在项目根目录运行 `build_windows.bat`。生成的安装包位于 `release` 目录。

更新安装会先请求运行中的程序安全退出：等待导入、备份、恢复或迁移完成，保存尚未保存的备注，然后退出。程序退出及文件释放前，安装器不会覆盖程序文件；等待期间可重试或取消安装。从 **0.7.2 或更早版本** 首次更新时，旧版尚不支持该退出请求，请先保存备注，在任务栏托盘右键图标选择“退出 Plasmora”，再继续安装。关闭窗口可能只是最小化到托盘。取消更新后，可继续使用原程序。

### 从源码启动

开发环境需要 Windows、Python 3.12 和 `pip`。在项目根目录执行：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 desktop.py
```

也可以运行 `start.bat`（它会调用本机的 `py -3`）。打包脚本为 `build_windows.bat`，生成安装包还需要 Inno Setup。

## 使用方法

1. 启动程序，点击“导入质粒”选择 `.dna` 文件，或把文件从资源管理器拖入窗口。首次导入前可通过“存储位置”选择原件目录。
2. 在左侧创建分组。把文件拖到分组可在导入时归类；进入分组后也可从全部质粒中勾选并加入。右键分组可重命名或删除。
3. 在列表中搜索、排序或筛选质粒。“包含 Feature 与备注”和“搜索引物名称”分别控制搜索范围；文件名始终参与搜索。同义词集群可在“同义词集群”中维护。
4. 点击质粒，在右侧切换“质粒图谱 / 引物信息”，查看 Feature 或引物。引物模式可按名称筛选和复制完整序列；备注和所属分组仍显示在下面。右键质粒可重命名、调整分组、在 SnapGene 中打开、导出或删除。
5. 使用“批量导出”生成 ZIP；使用“备份与恢复”保存或恢复整个仓库。删除后可在左侧“回收站”恢复质粒；从备份恢复前的仓库可在“备份与恢复 → 查看自动备份”中找回。
6. 在 SnapGene 保存仓库原件后，程序会在文件写入稳定后自动更新对应记录；也可使用顶部“同步仓库”手动检查全部原件。关闭方式、配色和版本信息可在设置中查看。
7. 需要保留每天的文件版本时，在设置中勾选“按日更改生成副本”，再通过右键“在 SnapGene 中打开”编辑。右键“查看该文件所有副本”可浏览原件和每日副本。关闭选项后继续编辑最新副本，已有历史仍保留。

> “在 SnapGene 中打开”需要本机已安装可打开 `.dna` 文件的 SnapGene。Plasmora 的预览功能不依赖 SnapGene。

## 输入与输出示例

以下是操作示例，需自行准备有效的 SnapGene `.dna` 文件；示例文件并非项目附带数据。

### 导入、分组与搜索

**输入**：将包含名称为 `IP3R1` 的 Feature 的 `construct.dna` 拖到“信号通路”分组。

**输出**：仓库中保存一份原件；列表出现 `construct.dna`，其 Feature 标签包含 `IP3R1`，所属分组为“信号通路”。默认同义词集群包含 `ITPR1` 和 `IP3R1`，因此启用 Feature 搜索时输入 `ITPR1` 也能找到该质粒。两个搜索范围选项均关闭时，只有文件名本身匹配才会出现。

### 引物信息与搜索

**输入**：导入一个在 SnapGene 中保存了引物 `Check-F` 的 `.dna` 文件，在右侧选择“引物信息”。

**输出**：显示 `Check-F` 的名称、完整序列（包括 5′ 尾部）和文件中保存的结合信息。开启左侧“搜索引物名称”后，搜索 `Check-F` 可找到该质粒；默认关闭时引物名称不参与搜索。

引物名称搜索只读取本地索引。升级后已有质粒的引物名称在后台补齐，可通过“同步仓库”手动补齐。引物结合位置使用从 1 开始的闭区间坐标；Tm 仅显示文件保存的数值，未保存时不估算。含模糊碱基的序列不显示 GC%。没有保存引物的文件显示空状态，不从 Feature 名称推测引物。

### 重复文件

**输入**：再次导入文件名和内容均与仓库记录相同的 `construct.dna`。

**输出**：程序识别为重复，不再新增记录。若内容相同但文件名不同，则作为另一条质粒导入；若文件名相同而内容不同，程序提供保留两份并按 `construct (1).dna` 形式命名、保留原文件或替换原文件的选择。

### 按日保存与历史预览

**输入**：启用按日副本，10 月 8 日通过右键在 SnapGene 中打开 `construct.dna` 并保存，10 月 9 日再次打开并保存。

**输出**：保留 `construct.dna` 导入原件，并生成 `construct (2026-10-08).dna`、`construct (2026-10-09).dna`。同一天多次保存更新当天副本，不记录每次保存的独立版本；当天仅打开而未修改也会建立工作副本。跨夜未关闭 SnapGene 时，次日保存的新内容会归入当天副本，前一天的内容保留。已打开的历史文件继续保存时，也会捕获新内容并恢复该历史文件。

副本归属于同一条质粒，不增加总仓库中的质粒数量。分组、备注和收藏属于这条质粒，所有副本共享这些信息；图谱和引物信息读取所选副本。列表搜索使用最新版本的索引。原件和历史副本的校验快照由程序管理，备份、恢复、回收站和存储目录迁移均包含版本历史。此功能按本机日期工作，不能替代离线备份。

### 批量导出

**输入**：选中若干质粒，执行“批量导出”，指定 `plasmids.zip`。

**输出**：ZIP 包包含原件及索引清单，例如：

```text
plasmids.zip
├─ 质粒/
│  └─ construct.dna
└─ 质粒清单.csv
```

CSV 清单记录仓库编号、导出文件名、质粒名称、文件大小、导入时间、Feature 标签、所属分组、备注和 SHA-256。单个导出则生成一个 `.dna` 文件；备份生成 `.plasmora` 文件，可通过“备份与恢复”导入。

## 数据位置

- 默认原件目录：`%USERPROFILE%\Documents\Plasmora\原件`，可在程序中修改；修改时程序会迁移已管理的原件。
- 日副本与原件保存在同一仓库目录，历史校验快照位于其下的 `.plasmora-history` 子目录，由程序维护。
- 本地索引数据库：`%LOCALAPPDATA%\PlasmidLibrary\library.sqlite3`。
- 回收站文件与记录：`%LOCALAPPDATA%\PlasmidLibrary\Trash` 和 `trash.sqlite3`。
- 恢复前自动备份：`%LOCALAPPDATA%\PlasmidLibrary\rollback`。
- 运行日志：`%LOCALAPPDATA%\PlasmidLibrary\logs\Plasmora.log`，最多保留 3 份轮换日志。

请使用程序内的备份功能保存可恢复的仓库副本。程序仅接收能通过 SnapGene 格式校验的 `.dna` 文件。
